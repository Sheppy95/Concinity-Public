# Concinnity Interactive: Open Source Tools

**Tools for community-driven compute, transparency, and information integrity.**

Concinnity Interactive builds software designed for autonomy, transparency, and verifiable data integrity. This collection contains our open-source tools—high-performance, local-first utilities built to keep users in command of their own environments.

## The Software Fleet

Our suite is engineered for performance, designed to integrate seamlessly into community environments while maintaining a zero-bloat standard.

* **Archon Scribe**: An optimized, high-fidelity engine for Text-to-Speech and Speech-to-Text conversion. Built for speed, designed for local execution.
* **SmithWorks**: A dedicated interface tailored for interaction with specialized, reasoning-based AI models. It bridges the gap between raw compute and functional output.
* **LOGOs**: A full-featured moderation and community management bot for Discord. With 105 commands and 40 database tables, LOGOs handles everything from verification and invite control to ticket management and voice-channel accountability.



## Freedom of Information

We believe that digital systems should be verifiable. Our audit framework provides the clarity needed to challenge opaque infrastructure.

* **LcF (Audit Tooling)**: The core audit framework. LcF provides deep-level visibility into system behavior, ensuring that black-box environments are held to a standard of structural integrity.
* **Web Browser Claims Extension**: An essential verification layer. This tool validates the provenance of online content, shielding the user from misinformation at the point of consumption.
* **Library of Alexandria**: A decentralized, immutable archive. A permanent repository for fundamental knowledge, designed to endure and remain accessible regardless of the volatility of centralized networks.
